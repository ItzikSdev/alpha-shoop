# SEO Checklist — store + every product

Run after adding/editing products or store copy. Storefronts are ENGLISH-ONLY.

## Store-level SEO
- [ ] Unique, keyword-rich `<title>` + meta description on home, collections, product pages.
- [ ] One `<h1>` per page; logical heading order.
- [ ] Clean, readable URLs/handles (no supplier codes, no gibberish).
- [ ] `robots.txt` + `sitemap.xml` resolve; canonical set on product pages.
- [ ] Fast: images sized/lazy-loaded, no giant assets.

## Per-product SEO — "selling text that states everything needed"
For EVERY product:
- [ ] **Unique title**: baby + garment type + key feature (e.g. "Organic Cotton Footed Romper").
      No supplier codes/jargon, no foreign language.
- [ ] **Unique meta description** (~150–160 chars), benefit-led (organic cotton, gift-ready, sizing).
- [ ] **Unique body copy** — never reused across products; covers material, fit/sizing, features,
      care, and who it's for (new parents / gift-givers). Lead with the organic-cotton angle.
- [ ] **Descriptive alt text** on every image.

## Media integrity (per product)
- [ ] **No repeated/near-duplicate images within the same product** (dedupe by image CONTENT,
      not filename — Shopify re-hosts with new names). One image per distinct shot.
- [ ] Enough good, sellable images (image-light 1–2 photo products are not acceptable).
- [ ] Color variant bound to its own photo (clicking a color swaps the main image).

## Catalog integrity
- [ ] **No duplicate products** — never the same item listed twice (same title or same main image).
- [ ] **Price present, never `$0`** — every variant priced from the mapped retail.
- [ ] **Price not too high** — sanity-check retail vs. CJ cost + competitor prices; flag anything
      priced unreasonably above market (kills conversion) or below a healthy net margin.

**Report:** per product, list any ✗; fix titles/copy/alt, remove dup images/products, fix prices.
