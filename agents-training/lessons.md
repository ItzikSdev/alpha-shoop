# Landing Page Design Lessons

Cumulative structural-pattern insights extracted from reference e-commerce
stores, session over session. **Read this file FIRST** at the start of every
training session — before analyzing any new reference site — so later
sessions build on prior findings instead of starting from zero.

Hard rules governing every entry below (never violate when adding more):
- Structural / placement / hierarchy patterns only — what's near what, in
  what order, how it's grouped.
- NEVER copy actual marketing text, images, logos, or exact CSS from a
  reference site — every lesson is a general, reusable design principle.
- Skip a pattern here if it's already covered by an existing lesson below
  (check before appending, even if the new source phrases it differently).

## Patterns

### Urgency & Scarcity
- A dedicated urgency block (hint=urgency) appears near the primary price section, often used to highlight limited-time offers or stock availability. _(source: funvibeshub.com)_
- Urgency elements are typically placed above or adjacent to price blocks to reinforce time-sensitive purchasing incentives. _(source: funvibeshub.com)_

### Call to Action Placement
- CTA buttons (hint=cta) are densely clustered in the hero section and repeated throughout the page, ensuring visibility both above and below the fold. _(source: funvibeshub.com)_
- CTA buttons often appear alongside product galleries, reviews, and price blocks, creating multiple conversion touchpoints. _(source: funvibeshub.com)_

### Product Gallery Layout
- The gallery (hint=gallery) uses a grid of image-button pairs, with each image linked to an interactive element (e.g., quick view, add to cart). _(source: funvibeshub.com)_
- Gallery buttons are consistently placed below or beside product images, maintaining a uniform visual rhythm. _(source: funvibeshub.com)_

### Price & Discount Presentation
- Price-related content (hint=price, hint=discount) is grouped in dedicated blocks, often including original price, discounted price, and trust indicators. _(source: funvibeshub.com)_
- Discounted price elements are visually emphasized (e.g., strikethrough original price, bold discount tags) to highlight savings. _(source: funvibeshub.com)_
