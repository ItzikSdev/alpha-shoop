# Landing Page Design Lessons

Cumulative structural-pattern insights extracted from reference e-commerce
stores, session over session. **Read this file FIRST** at the start of every
training session — before analyzing any new reference site — so later
sessions build on prior findings instead of starting from zero.

Hard rules governing every entry below (never violate when adding more):
- Structural / placement / hierarchy patterns only — what's near what, in
  what order, how it's grouped.
- NEVER copy actual marketing text, images, logos, or exact CSS from a
  reference site — every lesson is a general, reusable design principle.
- Skip a pattern here if it's already covered by an existing lesson below
  (check before appending, even if the new source phrases it differently).

## Patterns

### Urgency & Scarcity
- A dedicated urgency block (hint=urgency) appears near the primary price section, often used to highlight limited-time offers or stock availability. _(source: funvibeshub.com)_
- Urgency elements are typically placed above or adjacent to price blocks to reinforce time-sensitive purchasing incentives. _(source: funvibeshub.com)_

### Call to Action Placement
- CTA buttons (hint=cta) are densely clustered in the hero section and repeated throughout the page, ensuring visibility both above and below the fold. _(source: funvibeshub.com)_
- CTA buttons often appear alongside product galleries, reviews, and price blocks, creating multiple conversion touchpoints. _(source: funvibeshub.com)_

### Product Gallery Layout
- A dense grid of gallery buttons and images suggests a horizontally scrollable or carousel-style product view. _(source: starnestshop.com)_
- Gallery elements are interspersed with price and trust signals, balancing visual engagement with functional information. _(source: starnestshop.com)_
- The gallery (hint=gallery) uses a grid of image-button pairs, with each image linked to an interactive element (e.g., quick view, add to cart). _(source: funvibeshub.com)_
- Gallery buttons are consistently placed below or beside product images, maintaining a uniform visual rhythm. _(source: funvibeshub.com)_

### Price & Discount Presentation
- Price-related content (hint=price, hint=discount) is grouped in dedicated blocks, often including original price, discounted price, and trust indicators. _(source: funvibeshub.com)_
- Discounted price elements are visually emphasized (e.g., strikethrough original price, bold discount tags) to highlight savings. _(source: funvibeshub.com)_

### Trust & Credibility
- Trust elements (badges, testimonials) are grouped into dedicated sections with multiple nested containers to reinforce credibility. _(source: octocuddles.store)_
- Multiple trust-related spans and divs are clustered near the bottom of the page, often following product details or pricing. _(source: octocuddles.store)_
- Trust signals (e.g., trust badges, reviews) are placed near pricing and product descriptions to reinforce credibility at key decision points. _(source: minixmasbaby.myshopify.com)_
- Multiple trust elements appear in separate sections, suggesting a layered approach to building consumer confidence. _(source: minixmasbaby.myshopify.com)_

### Price & Value
- Price-related content (original price, discounted price, and value indicators) is grouped closely in a dedicated section to highlight promotions and savings. _(source: minixmasbaby.myshopify.com)_
- Price-like elements are repeated in multiple locations, possibly to reinforce value propositions across different user engagement stages. _(source: minixmasbaby.myshopify.com)_

### Call to Action (CTA) Placement
- CTA buttons are repeated in distinct areas of the page, including above and below fold, to maintain engagement and guide conversions at multiple touchpoints. _(source: minixmasbaby.myshopify.com)_
- CTAs are often paired with trust elements or pricing blocks, suggesting a strategic alignment of urgency, value, and action. _(source: minixmasbaby.myshopify.com)_

### Pricing & Discounts
- Price blocks are repeated with variations (e.g., base price, discounted price, final price) using nested divs and spans to emphasize savings. _(source: octocuddles.store)_
- Discount sections include both textual hints and visual containers to highlight promotions, often placed near product galleries or reviews. _(source: octocuddles.store)_

### Reviews & Testimonials
- Review elements are distributed across multiple sections, with dedicated blocks containing spans and divs to organize star ratings, comments, and metadata. _(source: octocuddles.store)_
- Review sections are often positioned near the top and bottom of the page, creating a "first impression + social proof" layout pattern. _(source: octocuddles.store)_

### FAQ Layout
- FAQ sections use nested divs and buttons to create an accordion-style interface, with each question paired with a toggleable answer block. _(source: octocuddles.store)_
- Multiple FAQ blocks are structured with consistent hierarchy (h2 for headers, divs for content) to ensure scannability and user control. _(source: octocuddles.store)_

### Call-to-Action Placement
- Multiple buttons are clustered in high-traffic areas (e.g., near the hero, within FAQ sections, and in standalone blocks) to maximize user interaction opportunities. _(source: beelyra.com)_
- Buttons are frequently paired with headings (h2/h3) to create clear, actionable micro-sections. _(source: beelyra.com)_
- Multiple CTA buttons are clustered near product variants and reviews, reinforcing conversion points. _(source: starnestshop.com)_
- A CTA button repeats both above and below the fold, ensuring visibility across scroll positions. _(source: starnestshop.com)_

### Price & Discount Hierarchy
- Price-like elements are grouped with discount indicators and trust signals in multiple sections, emphasizing value. _(source: starnestshop.com)_
- A dedicated "discount,trust" block appears near the main price, creating a cohesive value proposition cluster. _(source: starnestshop.com)_

### Hero Section Composition
- A hero section combines a headline, supporting text, and a primary call-to-action button within a single visual block. _(source: beelyra.com)_
- Supporting text is often repeated in multiple paragraphs to reinforce messaging before the CTA. _(source: beelyra.com)_

### FAQ Information Hierarchy
- FAQ sections use nested headings (h3) and collapsible elements to organize questions and answers in a scannable format. _(source: beelyra.com)_
- A dedicated anchor link (hints=faq) is placed near the top of the FAQ block to improve navigation. _(source: beelyra.com)_

### Gallery Item Interactivity
- Each gallery image is paired with a dedicated button, suggesting a "view details" or "quick action" micro-CTA per item _(source: funvibeshub.com)_
- Buttons in gallery sections are consistently placed adjacent to their corresponding image, creating a 1:1 visual association between media and action _(source: funvibeshub.com)_

### Repeated CTA Grouping
- Multiple buttons with "cta" hints appear in clusters near product variants, pricing sections, and reviews, reinforcing user action through repetition _(source: funvibeshub.com)_
- Gallery buttons are systematically distributed across the page in predictable intervals, creating a rhythmic visual pattern _(source: funvibeshub.com)_

### Distributed CTA Placement
- Call-to-action buttons appear in multiple distinct sections rather than being grouped together in a single area _(source: minixmasbaby.myshopify.com)_
- CTA elements are interspersed with product information blocks and trust signals across the page hierarchy _(source: minixmasbaby.myshopify.com)_

### Trust Element Repetition
- Trust-related components (e.g. icons, badges) are repeated in multiple non-consecutive sections of the layout _(source: minixmasbaby.myshopify.com)_
- Trust signals appear both above and below key decision points like pricing blocks and CTA buttons _(source: minixmasbaby.myshopify.com)_

### Review Integration Across Sections
- Review elements appear in multiple distinct sections (e.g., near product gallery, within dedicated review blocks, and alongside trust elements), suggesting a strategy to reinforce social proof contextually rather than isolating it to one area. _(source: octocuddles.store)_
- Review-related content is interwoven with price/discount sections, potentially leveraging peer validation to support purchasing decisions at critical decision points. _(source: octocuddles.store)_

### Discount Layering in Price Blocks
- Price sections frequently include nested discount indicators (e.g., spans with "price,discount" hints) directly adjacent to base price elements, creating a visual hierarchy that emphasizes savings without obscuring original pricing. _(source: octocuddles.store)_
- Discount-related content is repeated across multiple price blocks (e.g., #584, #621), suggesting a pattern of reinforcing promotional messaging through redundancy. _(source: octocuddles.store)_

### Price Information Reinforcement Through Repetition
- Price-like elements (e.g., spans with "price" hints) are repeated across multiple distinct blocks (e.g., #255, #637, #732), often grouped with discount or trust indicators, creating redundant emphasis on pricing. _(source: starnestshop.com)_
- Each price block includes at least one standalone span for the base price and another for discounted values, even when nested within overlapping divs (e.g., #633, #728). _(source: starnestshop.com)_

### Gallery Item Consistency
- Each gallery item (identified by "gallery" hints) pairs a button with an image, maintaining a 1:1 ratio of interactive elements to visual content throughout the gallery section. _(source: starnestshop.com)_
- Buttons associated with gallery items are consistently placed immediately adjacent to their corresponding images, regardless of section depth or container hierarchy. _(source: starnestshop.com)_

### Product Variant Selection Layout
- A dedicated variant selection section groups multiple buttons and labels in a single container, allowing users to toggle between product options without leaving the main product view _(source: funvibeshub.com)_
- Each variant option is presented as a standalone button with visual consistency across all selections _(source: funvibeshub.com)_

### Gallery Item Button-Image Pairing
- Each gallery item combines a button with an adjacent image in a fixed layout pattern, creating a clickable thumbnail interface _(source: funvibeshub.com)_
- The button and image are consistently aligned horizontally with no intervening text or spacing between them _(source: funvibeshub.com)_

### Price Information Reinforcement Through Nested Containers
- Multiple price-related elements (spans/divs with price hints) are grouped within distinct containers (e.g., #433, #438), each containing redundant price-like text to reinforce value. _(source: minixmasbaby.myshopify.com)_
- Price-like content appears in multiple nested layers (e.g., spans inside divs with price/discount hints), creating visual and structural repetition. _(source: minixmasbaby.myshopify.com)_

### Trust Element Proximity to Reviews
- Trust elements (e.g., #421, #451) are placed directly adjacent to review blocks (e.g., #432), creating a cohesive cluster of credibility signals. _(source: minixmasbaby.myshopify.com)_
- Trust-related text (spans with trust hints) appears in proximity to both CTAs and review sections, reinforcing trust through contextual grouping. _(source: minixmasbaby.myshopify.com)_

### Trust Elements Embedded in Price Sections
- Trust-related elements (e.g., icons, badges) are nested within price blocks rather than placed separately, reinforcing credibility directly alongside pricing information. _(source: starnestshop.com)_
- Multiple trust indicators appear within the same price container, creating a dense cluster of trust signals to reduce perceived risk. _(source: starnestshop.com)_

### Gallery Items with Multiple Interactive Elements
- Each gallery item includes multiple buttons (up to 10 per item) alongside images, suggesting layered interactivity options (e.g., zoom, share, quick view). _(source: starnestshop.com)_
- Buttons are distributed vertically within gallery items, creating a scrollable micro-interaction zone that encourages engagement. _(source: starnestshop.com)_
